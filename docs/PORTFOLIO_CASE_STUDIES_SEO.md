# إدارة الأعمال وتحسين محركات البحث — موقع عبيدة حجازي

## لوحة الإدارة Sanity
1. افتح `/admin` بحسابك المخوّل. لا يمكن للزائر العادي تعديل المحتوى.
2. اختر **الأعمال → مشروع جديد**، واكتب الاسم والمعرّف والتصنيف.
3. ارفع صورة الغلاف، ثم الصور والفيديوهات في قسم الوسائط؛ اسحبها لتغيير ترتيب العرض.
4. حقول **دوري في المشروع** و**التحدي** و**الحل** و**الكلمات المفتاحية** اختيارية. لا تنشر معلومات عميل دون موافقته.
5. صور **قبل وبعد** اختيارية ولا يظهر السلايدر إلا عند رفع صورتين حقيقيتين.
6. اترك المشروع كمسودة واستخدم **معاينة** قبل الضغط على **نشر**. المشاريع التجريبية أو المخفية لا تظهر في صفحات الإنتاج.
7. بعد النشر، يمكن مشاركة رابط `/projects/<slug>` مباشرة، ويظهر المشروع في معرضه حسب تصنيفه.

## Search Console
- افتح https://search.google.com/search-console وأضف رابط الاستضافة الفعلي (دومينك إن توفر).
- إذا اخترت التحقق بعلامة HTML، أضف رمز التحقق **فقط** في متغير Netlify `GOOGLE_SITE_VERIFICATION` وأعد النشر. لا تضع وسم HTML كاملاً في المتغير.
- قدّم الرابط `/sitemap.xml`. تتضمن الخريطة فقط المشاريع المنشورة الحقيقية وصفحات الخدمات العربية.
- لا يمكننا إدخال الموقع إلى حساب Google أو تأكيد ملكيته دون إجراء منك.

## لوحة جودة الموقع
- لوحة الإدارة ← الإحصائيات ← جودة الموقع: يمكنك فحص PageSpeed (موبايل/كمبيوتر) وقراءة رقم Commit الذي توفّره Netlify.
- إذا ظهرت مشكلة حصة Google يمكنك ضبط `PAGESPEED_API_KEY` في متغيرات الخادم، أو فتح https://pagespeed.web.dev/ مباشرة.
- الأرقام على اللوحة تقارير خارجية فعلية عند الطلب؛ المختبرية ليست بيانات مستخدمين حقيقية. INP لا يظهر إلا إذا توفر قياس ميداني.
- تأكد من متغير `NEXT_PUBLIC_SITE_URL` حتى يتم فحص الرابط الحقيقي، لا localhost.
- نُظهر `COMMIT_REF` أو `BRANCH` إذا وفّرتهما منصة النشر؛ في غير ذلك «غير متاح».

## الأداء وتجربة الموبايل
- الصور تستخدم next/image بأبعاد محددة؛ صور خارج نطاق العرض تُحمَّل كسولة افتراضياً، وصور الغلاف الأساسية لها أولوية.
- معاينة فيديوهات المونتاج مُعطلة التحميل مسبقاً؛ الملف يُطلب عند التشغيل.
- لا تفعّل صور قبل/بعد وهمية أو شهادات غير موافق عليها.
- راجع على Safari iOS، Chrome Android، Chrome Desktop: صور المعرض، Lightbox، السحب، نافذة طلب السعر، تداخل الأزرار الثابتة، مقاسات لمس الأزرار وإعدادات تقليل الحركة.
