# الإحصائيات الحقيقية (Umami)

الموقع يرسل أحداثاً منفصلة عند الضغط على أزرار واتساب، لكن **لا تُسجَّل أي أرقام قبل ربط أداة تحليلات**. اخترنا Umami لأنه مجاني للمواقع الصغيرة، ويحترم الخصوصية دون ملفات تعريف ارتباط، وسهل الإعداد.

## الإعداد (5 دقائق)
1. أنشئ حساباً على https://cloud.umami.is وأضف موقعك (Add website) باسم النطاق النهائي.
2. انسخ **Website ID**.
3. أضف إلى متغيرات البيئة على الاستضافة:
   ```
   NEXT_PUBLIC_UMAMI_WEBSITE_ID=المعرف
   ```
4. (اختياري) من إعدادات الموقع في Umami فعّل **Share URL** وضع الرابط في:
   ```
   NEXT_PUBLIC_UMAMI_SHARE_URL=https://cloud.umami.is/share/...
   ```
   سيظهر زر «فتح لوحة الزيارات» في `/admin ← الإحصائيات`.
5. أعد نشر الموقع.

## الأحداث المسجّلة
| الحدث | متى يُسجَّل |
|---|---|
| `whatsapp_click` | زر واتساب العام (الترويسة، الزر العائم، التذييل) |
| `consultation_whatsapp_click` | إرسال نموذج «احجز استشارتك المجانية» |
| `quote_whatsapp_click` | إرسال نموذج «اطلب عرض سعر» |
| `calendar_open` | فتح تقويم Cal.com |
| `similar_project_click` | زر «أرغب في مشروع مشابه» داخل عارض الأعمال |

**مهم:** الحدث يعني أن الزائر فتح واتساب أو التقويم، ولا يعني أن الرسالة أُرسلت أو أن الحجز تأكد.
