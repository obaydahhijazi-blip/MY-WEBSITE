تشغيل موقع عبيدة حجازي على الكمبيوتر (Windows)
=================================================

1) ثبت Node.js LTS (يفضل 22 أو 24) من:
   https://nodejs.org/en/download
   أعد فتح المجلد بعد انتهاء التثبيت.

2) فك ضغط الحزمة بالكامل في مجلد على الكمبيوتر.
   لا تشغّل الملفات وهي داخل ZIP.

3) اضغط مرتين على:
   START_LOCAL.cmd

4) أول مرة: يحتاج اتصالاً بالإنترنت لتنزيل المكتبات بواسطة npm.
   انتظر انتهاء التثبيت وظهور نافذة خادم الموقع.
   سيُفتح المتصفح تلقائياً على:
   http://localhost:3000

5) لوحة التحكم (بعد تشغيل الموقع):
   http://localhost:3000/admin
   أو افتح الملف OPEN_ADMIN.cmd

   معرف Sanity العام مضبوط مسبقاً:
   Project ID: iz5tq94u
   Dataset: production

   للدخول إلى إدارة Sanity محلياً، أضف في مشروع Sanity
   API > CORS origins:
   http://localhost:3000
   مع تفعيل Allow credentials.
   سجّل الدخول بالحساب المصرح له في Sanity.
   إن لم تكن بيانات Sanity جاهزة، تبقى الصفحة العامة قادرة على استخدام المحتوى المحلي الاحتياطي.

6) لإيقاف الموقع أغلق نافذة الخادم التي تعرض npm run dev
   أو اضغط Ctrl+C داخلها.

7) خط KO Sans الأصلي:
   ملفات الخط المرخصة غير مضمّنة في هذه الحزمة.
   الموقع لديه خط بديل، لكن لتفعيل خطك الأصلي انسخ الملفات
   من مجلد خطوطك على جهازك وفق docs/FONTS_KO_SANS.md
   أو استخدم scripts/setup-ko-sans.ps1 .

مهم:
- مشروع Next.js لا يعمل بفتح ملف HTML بالنقر المزدوج.
  يجب تشغيل الخادم المحلي عبر START_LOCAL.cmd.
- لا تضع مفاتيح API أو كلمات مرور في GitHub.
- الملف .env.local يتضمن معرف Sanity العام فقط، ولا يتضمن مفاتيح سرية.
- إذا لم يفتح الموقع، صوّر رسالة الخطأ في نافذة الخادم وأرسلها.

الملفات الأصلية للمشروع لم تُحذف؛ أُضيف فقط مشغّل محلي ودليل إعداد.
