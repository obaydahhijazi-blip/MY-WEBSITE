# حزمة تنفيذ الموقع الشخصي — عبيدة حجازي / V3.1

هذه الحزمة مرفقة بالبرومبت `PROMPT_FOR_CLAUDE.txt` لتنفيذ موقع شخصي احترافي في Claude Code.

## طريقة الاستخدام
1. ارفع ملف ZIP إلى Claude في مساحة تدعم قراءة الملفات، أو فك الضغط في مجلد المشروع وافتحه باستخدام Claude Code.
2. أرسل النص الكامل من `PROMPT_FOR_CLAUDE.txt` (انسخه من المحادثة أيضاً إن أردت).
3. اطلب من Claude تنفيذ موقع حقيقي وليس مجرد وصف أو Mockup، مع فحص الصور وتنفيذ أقسام الصفحة السبعة.
4. الصور المفككة الخاصة بالـ Hero موجودة في `assets/hero/layers/`.
5. المحتوى العربي قابل للتعديل في `content/site-content.ar.json`.

## المعتمد
- هوية شخصية: عبيدة حجازي، مصمم غرافيك ومختص بالإبداع البصري والذكاء الاصطناعي.
- واجهة عربية RTL بالكامل.
- افتتاحية داكنة مستوحاة مباشرة من غلاف الفيسبوك المفكك، يليها تصميم أبيض رسمي بسيط.
- التوجه: 70% رسمي / 30% إبداع (افتراض تصميمي قابل للتعديل).
- تفاعل خفيف بالماوس للطبقات المختلفة، مع بديل على الموبايل.
- واتساب: +963 964 766 503
- حجز استشارة مجانية 30 دقيقة مرتبط بجدولة حقيقية؛ إشعارات واتساب التلقائية تتطلب إعداد تكامل رسمي.

## مهم جداً
- أكّد المالك وجود ترخيص KO Sans. أُضيفت ملفات CSS وتجهيز نسخ الخط السبعة محلياً: `styles/ko-sans.css` و`scripts/setup-ko-sans.ps1`، وشرح مفصل في `docs/FONT_LICENSE_AND_SETUP.md`. ملفات الخط الثنائية نفسها غير موجودة في الحزمة؛ تُنسخ من ملفات المالك إلى `public/fonts` داخل المشروع.
- لا توجد بعد شعارات عملاء مُعتمدة، ولا قائمة نهائية بالأعمال؛ ملفات `content/clients.json` و`content/works.json` فارغة عن قصد.
- لم يتم إعداد حساب Cal.com أو ربط API واتساب. لا يُسمح للموقع بادعاء إتمام الحجز أو إرسال إشعار تلقائي قبل إتمام الربط.
- أي بريد إلكتروني غير مؤكد غير منشور. ولا تُنشر بيانات السيرة الذاتية الخاصة.
- رقم 7+ سنوات ظهر في الغلاف المقدم، وهو بحاجة لمراجعة نهائية من صاحب الموقع قبل النشر.
- الصور ضمن `references/social-style/` للاستلهام من هوية المصمم فقط، وليست معرض مشاريع مُعتمداً أو صوراً للعملاء.

## المجلدات
- `assets/hero/layers/`: الخلفية + صورة عبيدة + اسم الغلاف + الزخارف المستقلة.
- `assets/logo/`: شعار عبيدة الأصلي والصيغ المعالجة للعرض.
- لا تستخدم صوراً شخصية بديلة من مسودات سابقة. صورة عبيدة المعتمدة في الافتتاحية هي `assets/hero/layers/obaydah-portrait-cutout.png`، وقسم «من أنا؟» يمكن أن يكون نصياً من دون صورة إضافية.
- `references/`: الغلاف المركّب والكرت وأمثلة بوستات المستخدم للاستلهام.
- `content/`: بيانات عربية منظّمة، وقوائم عملاء وأعمال فارغة حتى يرسلها المستخدم.
- `docs/`: تعليمات التفاعل والحجز والنشر وقائمة الملفات.
